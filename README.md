# Akash Purwar Tech

React + Vite portfolio website for Akash Purwar.

## Run locally

```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Resume

Put the latest resume at:

`public/Akash_Purwar_Resume.pdf`

The Resume button will automatically download it.
